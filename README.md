# A little question for Elsie

A responsive, single-page date invitation. It uses only HTML, CSS, and JavaScript—there are no packages or build steps.

## Deploy on Render

1. Push this project to a GitHub repository.
2. In Render, choose **New + → Blueprint** and connect the repository.
3. Render will read `render.yaml` and publish the app as a static site.
4. When deployment finishes, share the `onrender.com` URL with Elsie.

You can also create a **Static Site** manually and set its publish directory to `public`.
